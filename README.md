## Development Setup

**Unity Editor:** `6000.3.8f1 (LTS)`. Install this exact version through Unity Hub before opening the project — Hub reads the pinned version from `ProjectSettings/ProjectVersion.txt` and will prompt to install it if missing. Do not click "Update Project" or upgrade to a newer Editor version without team agreement; staying on the pinned LTS build is what prevents editor updates from silently breaking the project.

**Git:** A standalone Git installation (e.g. [Git for Windows](https://git-scm.com/download/win)) is required, on `PATH`, in addition to any GUI client (GitHub Desktop, VS Code Source Control, etc.). A GUI client alone does not expose a `git` command to terminals or editor integrations.
